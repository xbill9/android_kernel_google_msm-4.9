=== 433912b5ec7230def455277e519f4a3305c6b758 2026-10-24
bonito: Build libui with LEGACY_GRALLOC

Android 17's libui only loads IMapper 4.0 and newer on API 36+, unless built
with LEGACY_GRALLOC. The sdm845 display stack provides IMapper 2.1, so the
composer HAL aborted with "gralloc-mapper is missing".

=== 2cbfb4ba20075d43eee94d851ac69ea7f30158aa 2026-10-26
bonito: Label /dev/ion

Android 17 removed /dev/ion from the platform file_contexts but kept
the ion_device type, so the node came up as device. With SELinux
enforcing, surfaceflinger, gralloc, the composer, keymaster,
gatekeeper and tee lose ION and the boot stops at a black screen; in
permissive boots 21 domains log denials on /dev/ion as device.

Android 17 removed every ion_device rule from the platform policy along
with the /dev/ion label. With the label back, an enforcing boot still
denies read on ion_device to surfaceflinger, keymaster, gatekeeper,
qseecomd (tee) and gralloc. This kernel has ION and no DMA-BUF heaps.

fwk_bufferhub is a private platform type and is left out.

=== 3f29377283f32269fd69fedf618822a7c3b5fc0a 2026-10-27
bonito: Stop CHRE after boot

The sensor DSP firmware rejects libchre_slpi_skel.so ("dlerror
undefined symbol #25 __sensors_island_start"), so chre_daemon_msm exits
and init restarts it about every 5 s: 146 starts and 1,870 CHRE error
lines in the first 14 minutes of a boot. Its only user, Active Edge, is
no longer built. Stop the service once boot completes; "start
vendor.chre" brings it back.

Tested on sargo with "stop vendor.chre": the service stayed stopped,
and the accelerometer and light sensor kept reporting.
